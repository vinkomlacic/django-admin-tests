## Issues Found

One issue found and fixed during implementation (not left open):
`RestrictedItemAdmin` initially only overrode `has_module_permission` and
`has_view_permission`. A live test caught that Django's changelist view
actually gates on `has_view_or_change_permission`, and a superuser still
passes the default `has_change_permission` — so the changelist returned 200
instead of the intended 403. Fixed by also overriding
`has_change_permission`, `has_add_permission`, and `has_delete_permission`.
Re-verified: all 8 tests pass.
